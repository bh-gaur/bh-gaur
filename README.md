### 👨‍💻 Professional Summary

I am a **DevOps & Cloud Engineer** specializing in modern cloud-native architectures, container orchestration, GitOps automation, and full-stack observability. 

My work centers on building reliable, cost-efficient, and secure cloud platforms:
- 🏗️ **Infrastructure as Code**: Multi-cloud provisioning on AWS, GCP, and OCI using Terraform & Terragrunt.
- ☸️ **Container Orchestration**: Production-grade Kubernetes (EKS, GKE, OKE), Helm charts, and microservice meshes.
- ⚡ **Observability & Reliability**: Deep experience designing OpenTelemetry distributed tracing and the Grafana LGTM stack (Loki, Grafana, Tempo, Mimir) with Grafana Alloy.
- 💰 **FinOps & Cloud Economics**: Authoring automated AWS cost optimization engines that eliminate cloud waste via real-time Price List APIs and batched CloudWatch telemetry.
